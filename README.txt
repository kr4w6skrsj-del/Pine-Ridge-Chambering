# Pine Ridge Chamber App V0.1

iPad-first chamber worksheet prototype.

## What works
- Tap-to-edit measurement boxes over the original chamber drawing
- Large quick-entry bar with Previous / Next buttons
- Chamber name and job details
- Automatic local saving in Safari
- Saved chamber list + search
- New / Duplicate / Delete
- Print / Save as PDF
- JSON backup and restore
- PWA manifest + offline service worker for GitHub Pages / HTTPS hosting

## iPad install
Host this folder on GitHub Pages (or another HTTPS web host), open the site in Safari,
then Share > Add to Home Screen.

Data is stored in the browser on that iPad, so use Backup occasionally.
